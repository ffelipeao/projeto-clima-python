# Projeto de Análise de Dados Climáticos com Python

Este projeto foi desenvolvido em aula com o objetivo de praticar o uso das bibliotecas:

- Requests
- JSON
- Pandas
- Matplotlib

## Fonte dos dados

Os dados foram obtidos por meio da API pública Open-Meteo.

## Funcionalidades

- Acessa dados climáticos online;
- Converte a resposta da API para JSON;
- Organiza os dados com Pandas;
- Gera análise exploratória simples;
- Cria gráficos de barras, pizza e dispersão.
